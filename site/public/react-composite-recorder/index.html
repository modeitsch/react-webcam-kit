React composite recorder

Record a screen share with a webcam picture-in-picture layer.

Use `useCompositeStream()` to draw multiple streams to a canvas, mix audio, and pass the final stream to `useMediaRecorder()`.

Install from npm View GitHub

Composite recorder example

const screen = useDisplayMedia({ audio: true, video: true });
const camera = useWebcam({ audio: true });
const composite = useCompositeStream({
  height: 720,
  width: 1280,
  layers: [
    { audio: true, fit: 'contain', stream: screen.stream },
    { audio: true, fit: 'cover', height: 180, width: 320, x: 940, y: 520, stream: camera.stream },
  ],
});
const recorder = useMediaRecorder({ quality: 'hd', stream: composite.stream });

Composite recording features

  • Draw screen, webcam, or other video streams in predictable layer order.
  • Mix audio from selected layers into one recordable stream.
  • Preview the composite canvas before recording.
