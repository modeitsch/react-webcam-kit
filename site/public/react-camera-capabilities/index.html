react-webcam-kit

React camera controls

Control torch, zoom, and focus from a React webcam stream.

Use `useCameraCapabilities()` to read what the active camera track supports and apply hardware controls only when the browser and device expose them.

Torch and zoom example

import { useCameraCapabilities, useWebcam } from 'react-webcam-kit';

export function CameraControls() {
  const camera = useWebcam({
    audio: false,
    videoConstraints: { facingMode: { ideal: 'environment' } },
  });
  const controls = useCameraCapabilities(camera.stream);
  const zoom = controls.capabilities.zoom;

  return (
    <>
      <video {...camera.getVideoProps()} />
      <button disabled={!controls.supportsTorch} onClick={() => controls.setTorch(!controls.torch)}>
        {controls.torch ? 'Torch off' : 'Torch on'}
      </button>
      {controls.supportsZoom && zoom ? (
        <input
          type="range"
          min={zoom.min}
          max={zoom.max}
          step={zoom.step}
          value={controls.zoom ?? zoom.min}
          onChange={(event) => controls.setZoom(Number(event.target.value))}
        />
      ) : null}
    </>
  );
}

Hardware control features

  • Feature-detect torch, zoom, and focus mode on the active video track.
  • Apply advanced constraints without hard-coding mobile-only assumptions.
  • Use scanner-friendly controls for low-light QR and barcode flows.
