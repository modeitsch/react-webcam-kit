react-webcam-kit

React chunk upload recorder

Upload MediaRecorder chunks while a React camera recording is still running.

Use `createChunkUploader()` with `useMediaRecorder({ timeslice })` so long camera or screen recordings do not need to wait for one final huge Blob before upload begins.

Install from npm View GitHub

Chunk upload example

const uploader = createChunkUploader({
  uploadId,
  url: '/api/recordings/chunks',
  onProgress: ({ uploaded }) => console.log(uploaded),
});
const recorder = useMediaRecorder({
  stream: camera.stream,
  timeslice: 5000,
  onDataAvailable: (event) => uploader.enqueue(event.data),
  onStop: () => uploader.complete(),
});

Upload features

  • Send chunks in order with retry and exponential backoff.
  • Track uploaded and pending chunks for recording UI.
  • Add auth metadata, upload IDs, and custom fields to every request.
